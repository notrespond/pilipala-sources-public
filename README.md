# PiliPala 番源公开镜像

本仓库只保存 PiliPala 看番客户端的 `dist/sources.json` 兜底清单，由自有服务器上的 `/opt/pilipala-sources/deploy.sh` 在有实质源变更时自动更新。

- 主源（Nginx）：`http://101.200.208.212/pilipala/sources.json`
- 本镜像（GitHub Raw）：`https://raw.githubusercontent.com/notrespond/pilipala-sources-public/main/dist/sources.json`

请勿在本仓库提交任何凭据或私密配置。
